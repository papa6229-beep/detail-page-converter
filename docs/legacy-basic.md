# 삭제된 "기본형" 코드 — 되감기 경위와 복원 기록

기본형 코드는 커밋으로 지워진 것이 아니라 **원격 브랜치 되감기(force-push)** 로 사라졌다.
원본 커밋들은 저자·날짜·해시까지 그대로 `legacy/basic-before-rewind` 브랜치에 되살려 두었다.

**코드 사본은 이 문서 옆에 두지 않는다.** 브랜치가 원본 그 자체이므로 거기서 꺼내 쓴다.

```
git fetch origin legacy/basic-before-rewind
git show origin/legacy/basic-before-rewind:app/basic.py
```

`app/` `tests/` 의 현재 코드는 이 작업으로 한 글자도 바뀌지 않았다.

## 1. 삭제된 커밋과 복원 기준 커밋

### 먼저 — 삭제는 "커밋" 이 아니었다

`app/basic.py` `app/bands.py` 를 지운 커밋은 이력에 **없다**.

```
git log --all --diff-filter=D -- app/basic.py app/bands.py   →  결과 없음
```

기본형 코드는 **원격 브랜치를 뒤로 되감는 force-push** 로 사라졌다.
이 저장소를 다시 받아 보면 그 흔적이 그대로 찍힌다.

```
$ git fetch --unshallow origin
 + 1a3e956...8fe84e5 main -> origin/main  (forced update)
```

`origin/main` 이 `1a3e956` → `8fe84e5` 로 **되감겼다**. 그 사이에 있던
기본형 커밋 9개와 병합 커밋 5개가 통째로 떨어져 나갔다.
같은 시점에 작업 브랜치 `claude/splitter-defect-fix-sc24x0` 도 되감겨,
지금은 `8fe84e5` 위에서 시작하는 **전혀 다른 일**(일본어 스크립트 번역기,
`78228cb` · 2026-08-22)을 담고 있다. 그래서 기본형 커밋들은 어느 원격 브랜치에서도
더는 닿지 않는다 — 이 클론의 로컬 `main` 만이 아직 그것들을 가리키고 있었다.

## 3. 당시 기본형 변환의 흐름 (입력 → 메인 → 본문 → 출력)

기본형은 단순형과 **전제가 반대**였다.

```
단순형   원본이 허접하다        → 원본 이미지를 손대지 않고 순서대로 싣는다
기본형   원본이 이미 완성 디자인 → 그대로 실으면 남의 쇼핑몰처럼 보인다
                                 → 원본은 재료로만 쓰고 우리 디자인으로 다시 짓는다
```

원칙은 한 줄이었다 — **자르기는 수학, 이해는 AI.** 모델 호출은 상품당 딱 1콜.

### ① 입력 — 엑셀 한 행

`POST /api/basic {sheet, row, key}` → `app/server.py:api_basic`

```
sheet.rows[row]                     엑셀 행 하나 (상품명 · 브랜드 · 본문 HTML)
source.parse(row.body)              본문 HTML 을 뜯어 이미지 URL 과 타이핑된 글로 가른다
source.classify(url) != "drop"      쓸 이미지 URL 만 남긴다
render.split_name(row.name)         상품명을 태그 · 한글명 · 영문명으로 가른다
body.lead_blocks                    원본에 직접 타이핑돼 있던 글 (typed)
```

### ② 본문 이미지 → 밴드 (픽셀 계층 · AI 0콜) — `app/bands.py`

```
convert.fetch(url)  →  RGB ndarray
bands.read(arr)
   split_bands()    행 흰 비율 ≥ 0.98 인 빈 행이 40px 이상 이어지면 거기서 자른다
                    48px 미만 조각은 버린다 (구분선·잡음)
   measure()        밴드마다 지표 6개 + fillRatio + dHash
   classify()       TEXT / MIXED / PHOTO / UNKNOWN
basic.is_promo()    네 변이 파란 테두리인 가로형 gif → PROMO
   ↓
cuts[]   band_00.jpg, band_01.jpg, …   (밴드 이미지 파일)
kinds[]  PHOTO · MIXED · UNKNOWN · TEXT · PROMO
hashes[] dHash
```

우리 단순형 분할기를 안 쓴 이유: 같은 원본을 고도몰 생성기는 **밴드 21개**, 우리 분할기는
**조각 14개**로 갈랐다. 저쪽 임계값(`largestCC 0.08` `smallCC 12` …)은 저쪽 21밴드를 재서
나온 값이라 다른 조각에 갖다 대면 뜻이 없다. 그래서 자르는 방식부터 저쪽 것을 옮겼다.
분할기가 둘이 되지만 그래야 **단순형 49개를 안 건드린다.**

### ③ 메인(대표컷) 고르기 — `app/basic.py`

두 갈래가 있었다.

- **모델이 고른다** (`take` 의 `main`) — 기본 경로.
- **모델 픽이 거부되면 로컬에서 다시 고른다** — `PHOTO → MIXED → UNKNOWN` 순으로
  훑어 첫 번째로 통과하는 밴드를 세운다. 대표컷이 비면 페이지가 통째로 무너지기 때문이다.

픽셀로만 고르던 시절의 잣대는 `shots()` / `pick_hero()` / `pick_photos()` 에 남아 있다 —
유채색 비율 · 글자꼴 덩어리 수 · 덩어리가 하나인가 · 제 네모를 꽉 채우는가.
절대값으로는 못 갈라서(`3f3780d`) **그 페이지에서 가장 깨끗한 컷을 바닥으로 삼고**
거기서 얼마까지 봐줄지로 정하는 상대 잣대를 썼다.

### ④ 본문 처리 — 모델 1콜 + 받은 뒤 검증

**보내기** (`basic.parts_for` + `basic.PROMPT`)

```
[text]  PROMPT              지시 — 요약정보 · 핵심특징 3개 · 그림 고르기 · Point 01·02
[text]  상품명 · 브랜드 · 원본에 타이핑돼 있던 글 전문
[text]  "[0](PHOTO) · 원본 맨 위"      ← 번호와 종류를 붙여서
[image] band_00.jpg (긴 변 900px, JPEG q85)
[text]  "[1](TEXT)"
[image] band_01.jpg
 …                                     밴드 전부를 보낸다 (차단이 아니라 순위)
```

**받기** (`llm.extract` → `basic.take`) — JSON 하나

```json
{"spec":{"타입":"","재질":"","무게":"","전원":""},
 "keys":[{"t":"제목","d":"한 줄 설명"}],
 "main":0,"feature":1,"package":null,"size":null,
 "point1":{"title":"","blocks":[{"i":2,"d":"설명"}]},
 "point2":{"title":"","blocks":[]},
 "notes":[]}
```

**검증** (`take`, 고도몰 쪽 Layer C) — 막는 것은 셋뿐

```
TEXT · PROMO 밴드를 그림 자리에 넣었다   → 그 자리를 비운다
같은 밴드를 두 자리에 넣었다             → 뒤엣것을 비운다
같은 사진이 다른 밴드로 또 들어왔다      → dHash 해밍거리 ≤ 10 이면 비운다
```

자리 잡는 순서는 `feature → size → package → main` (저쪽과 같다).
**잘못된 사진보다 빈 칸이 안전하다.** 다만 **캡션은 그림과 따로 살아서**,
그림이 비어도 설명은 그대로 남는다. `치수` 는 읽지 않고 `"상세페이지 참조"` 로 고정한다.

### ⑤ 출력 — HTML 한 장

```
basic.reframe(page.main)   HERO 자리(폭 700)에 맞게 대표컷을 다시 앉힌다
                           캔버스 폭 1000 · 제품이 0.86 · 세로/가로를 0.45~1.25 로 가둔다
basic.render_page(page)    HTML 문자열
   ① HERO         제조사 우상단 · 누끼컷 700 중앙 · 상품명 52px · 영문명 ·
                  스펙 1행(타입·재질·치수) 2행(무게·전원) · 패키지 오버레이
   ② KEY FEATURE  점 22px · `KEY/FEATURE` 72px · 부제 · 좌 이미지 + 우 카드 셋
   ③ 영문명 띠
   ④ Point 01 · Point 02   제목 + (설명 + 그림) 최대 3덩어리씩
   ⑤ SIZE         무게 알약이 그림 위에 얹힌다
   ⑥ GODO MALL 푸터
   ↓
WORK/out/{상품코드}.html
```

**빈 칸은 그리지 않는다.** 원본이 안 적은 스펙 항목은 칸 자체를 안 만든다 —
빈 칸을 그리면 손님은 "정보가 없다" 가 아니라 "값이 비어 있는 제품" 으로 읽는다.

CSS 선택자는 전부 `.gpage` 로 시작한다. 고도몰 상세설명 칸에 들어가므로
쇼핑몰 자체를 건드리면 안 된다. 렌더러는 단순형과 **완전히 따로** 뒀다 —
고도몰 쪽 보고서의 금지선 5번: *"기본형과 단순형의 렌더러를 합치지 말 것.
격리가 회귀 0을 만든 장치다."* 실제로 매 커밋 `단순형 49개 견주기 0건`.

### 흐름 한 줄 요약

```
엑셀 행
  → source.parse (본문 HTML → 이미지 URL + 타이핑된 글)
  → bands.read   (픽셀로 밴드 자르기 + 종류 붙이기, AI 0콜)
  → basic.parts_for + PROMPT → 모델 1콜
  → basic.take   (JSON 수용 + TEXT/PROMO/중복/dHash 차단 + 대표컷 재선택)
  → basic.reframe (HERO 재배치)
  → basic.render_page → WORK/out/{code}.html
```

## 4. 본문 변환이 실패했던 원인 — 코드·커밋 메시지에 남아 있는 것

문서(`docs/DESIGN.md` · `docs/ISSUES.md`)에는 기본형 기록이 없다.
기본형 작업은 문서를 한 줄도 건드리지 않았다. 전적은 **커밋 메시지와 코드 주석에만** 있다.

### ⓐ `NameError: name 'source' is not defined` — 본문 파싱 그 줄에서 죽었다 (`92365b2`)

가장 직접적인 "본문 변환 실패". `/api/basic` 이 Internal Server Error 였고 원인은 한 줄이었다.

```python
body = source.parse(row.body)   →  NameError: name 'source' is not defined
```

`server.py` 가 `from . import convert, excel, llm, render` 만 하고 있었다.
`basic` 도 함수 안에서만 불러오고 있었다. 커밋 메시지의 회고:

> **도구가 이미 잡을 수 있는 것이었다.** ruff 는 깔려 있었는데 검사에 안 들어가 있었다.
> F821(undefined name)이 기본 규칙에 있으므로 처음부터 걸렸을 일이다.
> … 이런 결함은 시험으로 잘 안 걸린다. 그 줄이 실제로 돌아야 터지는데

### ⓑ `Not Found` — 라우트가 `main()` 뒤에 있었다 (`053830c`)

화면에 `× 2489604 · Not Found`. `@app.post("/api/basic")` 을 파일 맨 끝,
`if __name__ == "__main__": main()` **뒤에** 붙여 놨다.
그렇게 실행하면 `main()` 이 서버를 띄우고 거기서 멈추므로 아래 줄은 영영 안 돈다 —
라우트가 등록될 기회 자체가 없었다.

> 서버는 멀쩡히 떴고 단추도 보이니 더 헷갈리는 종류의 결함이다.

조치: 기본형 코드를 `main()` 앞으로 옮기고 `test_길이_있어야_할_주소가_다_붙어_있다`
(있어야 할 주소 8개를 센다)로 불변식을 박았다. *"파일이 550줄이 넘어 눈으로는 못 지킨다."*

### ⓔ 대표컷이 **기둥**이 됐다 (`8f74032`)

### ⓕ 대표컷을 **하나도 못 골랐다** — 절대 임계값이 두 답을 냈다 (`3f3780d`)


통째로 올라가기 때문이다. 조치: 그 페이지에서 가장 깨끗한 컷을 바닥으로 삼는 상대 잣대.
