# detail-page-converter

기존 쇼핑몰(바나나몰)의 상품 상세페이지를 새 쇼핑몰(고도몰)용 디자인으로 자동 변환한다.

엑셀 한 장을 업로드하면 상세페이지가 새 디자인으로 나오는 것이 목표다.
변환 대상은 1000개가 넘고, 원본 구조에는 미리 다 알 수 없는 변형이 섞여 있다.

## 무엇을 바꾸고 무엇을 두는가

- **원본 이미지는 손대지 않는다.** 이미지 안의 일본어는 제조사 원본 아트이므로 번역·재작성 대상이 아니다
- 바꾸는 것은 **배치와 텍스트 조판**이다
- 최종 출력은 HTML — 고도몰 상세설명 필드에 들어간다

## 설계의 뼈대

원본마다 케이스를 나누면 조합이 폭발한다. 대신 모든 원본을 하나의 정규형으로 환원한다.

```
Product
├ meta    상품명 · 브랜드 · 가격 · 옵션        ← 엑셀
├ lead    리드 텍스트                          ← 상세설명 HTML
└ units[]  { image, caption?, optionTag? }
```

변형은 **유닛 배열을 얻는 어댑터에서만** 흡수한다. 렌더러와 디자인은 건드리지 않는다.

```
엑셀 ─┬─ meta
      ├─ lead
      └─ units[] ← 어댑터가 갈리는 유일한 지점
                   ├ 조각형   : HTML 파싱
                   └ 통이미지형: 분할
                            ↓
                    렌더러 · 디자인 (불변)
```

## 통과하지 못한 변환은 내보내지 않는다

1000개를 한 번에 변환하지 않는다. 결과물이 만족해야 할 **불변식**을 검사하고,
위반하면 결과물을 버리고 사유 코드와 함께 보류 풀로 보낸다.

600개 통과 / 400개 보류가, 1000개 변환 후 300개가 조용히 망가진 상태보다 낫다.
**보류는 실패가 아니라 정상 동작이다.**

보류 사유를 집계하면 그것이 곧 다음에 만들 어댑터 목록이 된다.
변형 케이스를 미리 수집할 필요가 없다.

## 돌리는 법

파이썬을 한 번만 설치하면, 그다음부터는 **파일 하나 더블클릭**이면 됩니다.

### 준비 — 파이썬 설치 (처음 한 번만)

**윈도우**

1. https://www.python.org/downloads/ 접속 → 노란 `Download Python` 버튼
2. 받은 파일 실행
3. **설치 첫 화면 맨 아래 `Add python.exe to PATH` 체크박스를 반드시 켭니다.** 이걸 놓치면 나중에 "파이썬이 없습니다"가 뜹니다
4. `Install Now` → 끝나면 `Close`

**맥** — 터미널(`⌘ + 스페이스` → `터미널`)에 아래 한 줄:

```
brew install python
```

`brew` 가 없다고 나오면 https://www.python.org/downloads/ 에서 받아 설치하세요.

### 코드 받기 (처음 한 번만)

1. https://github.com/papa6229-beep/detail-page-converter 접속
2. 브랜치를 `claude/splitter-defect-fix-sc24x0` 로 바꿉니다
3. 초록색 `Code` 버튼 → `Download ZIP`
4. 받은 zip 을 **압축 풀기**. 바탕화면 같은 찾기 쉬운 곳이면 됩니다

> 경로에 한글이나 띄어쓰기가 있어도 괜찮습니다.

### 실행

**윈도우** — 압축 푼 폴더 안의 **`실행.bat`** 을 더블클릭
(같은 내용의 `start.bat` 도 있습니다. 한글 파일명이 안 보이면 그쪽을 쓰세요)

**맥** — 터미널을 열고, `cd ` 를 친 뒤 **폴더를 터미널 창으로 끌어다 놓고** 엔터. 그다음:

```
./실행.sh
```

둘 다 결국 `start.py` 를 부릅니다. 터미널에서 직접 이렇게 해도 똑같습니다:

```
python start.py
```

처음 한 번은 준비하느라 2~3분 걸립니다. 그다음부터는 몇 초입니다.
준비가 끝나면 브라우저가 저절로 열립니다. 안 열리면 주소창에 직접:

```
http://127.0.0.1:8000
```

### 문구는 자동으로 뽑는다

원본의 글자가 어디 있느냐에 따라 두 갈래이고, **둘 다 사람이 치지 않는다.**

| 원본 | 글자가 있는 곳 | 뽑는 방법 |
| --- | --- | --- |
| 조각형 (닛포리류) | 상세설명 HTML **텍스트** | 파서가 그대로 읽는다. 준비물 없음 |
| 통이미지형 (텐가류) | 그림 속 **픽셀** | 잘라낸 글자 조각을 읽는다. API 키 필요 |

통이미지에 구워진 글자는 OCR 말고 읽을 방법이 없다. 첫 화면의 키 칸에
Anthropic API 키를 넣으면 **변환할 때 캡션이 저절로 채워진다.** 상품당 호출 1회.
키는 그 브라우저에만 저장되고 서버에 남지 않는다.

키가 없으면 잘라낸 글자 조각을 그대로 보여주므로 손으로 칠 수 있다. 어디까지나 대비책이다.

### 쓰는 순서

1. **엑셀 올리기** — 상품 목록이 뜹니다. 사전 게이트를 통과했는지 함께 보여줍니다
2. 상품 줄의 **`변환`** — 조각·짝·문구가 자동으로 채워집니다
3. **확인하고 다듬기** — 칸 위의 점선 이미지가 원본에서 잘라낸 그 자리입니다. 대조하며 고치세요
4. **`변환하기`** → 미리보기 · HTML 내려받기

엑셀이 아직 없으면 **통이미지 URL 하나만** 넣어도 시험됩니다. 첫 화면 아래쪽 URL 칸에
`https://cdn-banana.bizhost.kr/banana_img/product_image/man/2439903_detail_20180720.jpg`
를 넣고 `URL로 변환` 을 누르면 텐가가 나옵니다.

### 끄기

실행할 때 뜬 검은 창에서 `Ctrl + C`, 또는 그냥 창을 닫으면 됩니다.

### 안 될 때

| 증상 | 해결 |
| --- | --- |
| `Python not found` | 설치할 때 `Add python.exe to PATH` 를 안 켠 겁니다. 파이썬을 지우고 다시 설치하면서 그 체크박스를 켜세요 |
| 검은 창에 `'??'은(는) 내부 또는 외부 명령...` 이 쏟아짐 | 예전 버전입니다. 새로 받으세요 |
| 준비하다 멈췄거나 실패 | `.venv` 폴더를 지우고 다시 실행하면 처음부터 다시 만듭니다 |
| `주소를 사용할 수 없습니다` / 포트 충돌 | 이미 켜져 있습니다. 기존 검은 창을 닫고 다시 실행하세요 |
| 브라우저가 안 열림 | 주소창에 `http://127.0.0.1:8000` 직접 입력 |
| 방화벽 경고 | `취소` 눌러도 됩니다. 내 PC 안에서만 도는 프로그램이라 외부 접속이 필요 없습니다 |
| 그 외 | 검은 창에 찍힌 빨간 글씨를 그대로 알려주세요 |

내 컴퓨터 안에서만 돕니다(`127.0.0.1`). 상품 데이터가 밖으로 나가지 않습니다.
단, `자동으로 채우기` 버튼은 예외입니다 — 그건 캡션 조각을 API 로 보냅니다.

### API 키

첫 화면의 키 칸에 붙여넣고 `저장` 을 누르면 끝입니다. 그 브라우저에만 남습니다.

여러 사람이 쓰는 서버라면 환경변수 `ANTHROPIC_API_KEY` 로 넣어두면 화면에서 안 물어봅니다.

### 분할기만 따로

```
python -m slicer.cli <이미지파일> --out out/
```

조각 좌표와 번호 찍은 컨택트시트를 남깁니다.

## 현재 상태

텐가(통이미지 1장 · 2열 그리드 · 옵션 6종)가 **끝까지 변환된다.**
분할 0.94초, 2열 그리드 12칸 전부 이미지 1 + 캡션 1, 잉크 보존율 0.992.

확보한 샘플 5건(트리니티 · 버진루프 · 닛포리 · 텐가 · SI-X)에서 확인한 것:

- 이미지 경로는 세 갈래다. `banana_img/`를 통째로 버리면 텐가는 소재가 0장이 된다
- 분할기가 깨졌던 두 군데(어두운 배경 구간 · 2열 세로 절단)를 고쳤다.
  텐가 원본(650×3486)에서 2열 그리드 12칸이 전부 이미지 1 + 캡션 1 로 풀린다
- 다만 **원인은 처음 진단과 달랐다.** 어두웠던 것은 배경이 아니라 패널이었고,
  2열이 안 잡힌 것은 열 구분선이 페이지 중간부터 시작하기 때문이었다
- 캡션 귀속을 원본 화질에서 다시 쟀더니 **간격 두 무리가 겹친다.**
  축소본에서 보였던 "완전 분리"는 축소가 만든 착시였다

전체 설계와 사례별 진단은 [`docs/DESIGN.md`](docs/DESIGN.md)에 있다.
